# Dokumentacja

Ten folder zawiera uporządkowaną dokumentację i wiedzę o repozytorium.

## Spis treści

- `apis/`
  - dokumentacja integracji API (konfiguracja, endpointy, operacje)
- `specs/`
  - specyfikacje zmian
- `runbooks/`
  - instrukcje operacyjne dla agenta
- `apis/GitHub-API.md`
  - fallback API dla operacji na GitHub issues
