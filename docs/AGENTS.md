# AGENTS - docs/

Ten plik opisuje zawartość katalogu `docs/` i wskazuje, gdzie szukać informacji technicznych.

## Cel katalogu `docs/`

- Przechowywanie dokumentacji technicznej i operacyjnej projektu.
- Utrzymanie dokumentacji operacyjnej dla agentów w jednym miejscu.

## Zawartość

- `docs/AGENTS.md`
  - Indeks dokumentacji technicznej w `docs/`.
  - Opisuje, co, gdzie i po co znajduje się w tym katalogu.
- `docs/apis/AGENTS.md`
  - Indeks dokumentacji integracji API.
  - Zawiera mapę plików API i zasady prowadzenia dokumentacji API.
- `docs/specs/AGENTS.md`
  - Indeks specyfikacji funkcjonalności przygotowywanych do implementacji.
  - Zawiera mapę plików specyfikacji i zasady ich tworzenia.
- `docs/runbooks/AGENTS.md`
  - Indeks runbooków operacyjnych.
  - Zawiera mapę plików runbooków i zasady ich tworzenia.
- `docs/runbooks/publikowanie-na-github.md`
  - Runbook publikowania treści na GitHub bez problemów z formatowaniem.
- `docs/apis/GitHub-API.md`
  - Notatki i fallback API dla operacji na issues GitHub.
- `docs/runbooks/pr-review.md`
  - Procedura przeglądu Pull Requesta.
- `docs/runbooks/obsluga-issue-api.md`
  - Procedura obsługi issue przez API, gdy MCP lub `gh` nie wystarcza.
- `docs/runbooks/diagnostyka-ci.md`
  - Procedura diagnozy błędów GitHub Actions/CI.
- `docs/runbooks/przygotowanie-issue-i-specyfikacji.md`
  - Procedura przygotowania issue i wstępnej specyfikacji.
- `docs/runbooks/atomowe-commity.md`
  - Procedura dzielenia zmian na logiczne commity.

## Zasady aktualizacji

- Gdy dodajesz nowy plik do `docs/`, dopisz go w sekcji "Zawartość".
- Zachowuj opisy krótkie i praktyczne: co to jest, gdzie jest i do czego służy.
