# OpenEHDS — propozycja nowej strony

Jednostronicowa, responsywna witryna w czystym HTML, CSS i JavaScript. Nie wymaga procesu budowania.

## Uruchomienie

```bash
python3 -m http.server 4173
```

Następnie otwórz `http://localhost:4173`.
